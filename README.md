# Таймер для учебы

Это простой веб-таймер на 25 минут для работы по методу помодоро. Цель проекта — помочь сосредоточиться на учебе или работе без лишних отвлекающих элементов.

## Что умеет таймер

- отсчитывает 25 минут
- показывает оставшееся время крупным шрифтом
- запускается кнопкой "Старт"
- приостанавливается кнопкой "Пауза"
- сбрасывается обратно на 25 минут кнопкой "Сброс"

## Как пользоваться

1. Откройте файл `timer.html` в браузере.
2. Нажмите кнопку "Старт", чтобы начать отсчёт.
3. Во время работы таймер будет уменьшаться с 25:00 до 00:00.
4. Чтобы временно остановить таймер, нажмите "Пауза".
5. Чтобы вернуться к исходному времени 25:00, нажмите "Сброс".

## Файлы проекта

- `timer.html` — основная страница таймера.

## Примечание

Проект легко открыть локально в любом современном браузере без установки дополнительных зависимостей.
